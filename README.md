# MCA203P Java Lab Sheet 10 — Complete Solutions

Contains solutions for **10 questions** from the provided OOP Using Java assignment.

## Requirements

- JDK 8 or later (JDK 11/17/21 recommended)
- VS Code or Windows CMD / PowerShell / Linux Terminal
- No external dependencies

## Compile and run

In Windows CMD, open this extracted folder and run:

```bat
cd src
javac *.java
java Q01_StudentArrayList
```

Or use `compile_all.bat` from the extracted root on Windows. On Linux/macOS, use `bash compile_all.sh`.

## Files / question mapping

- Q01: `Q01_StudentArrayList.java` — Student ArrayList
- Q02: `Q02_EmployeeLinkedList.java` — Employee LinkedList
- Q03: `Q03_BookHashSet.java` — Book HashSet
- Q04: `Q04_ProductTreeSet.java` — Product TreeSet
- Q05: `Q05_StudentHashMap.java` — Student HashMap
- Q06: `Q06_ShapeCircleArrayList.java` — Shape/Circle ArrayList
- Q07: `Q07_CustomerVector.java` — Customer Vector
- Q08: `Q08_TaskStack.java` — Task Stack
- Q09: `Q09_PatientQueue.java` — Patient Queue
- Q10: `Q10_DepartmentTeacherMap.java` — Department/Teacher Map

All 10 numbered questions are standalone. Run `java Q01_StudentArrayList`, `java Q02_EmployeeLinkedList`, etc.
